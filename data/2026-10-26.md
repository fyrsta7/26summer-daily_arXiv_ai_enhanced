### [1] [A Topology-Guided GeoAI Agentic Framework for Urban Flood Screening](https://arxiv.org/abs/2610.30660)
*Yutian Tao,Haoan Feng,Xin Xu,Leila De Floriani*

Main category: cs.AI



Selection reason: 提出确定性控制器+LLM 仅在记录决策点介入、并用同一证据自检推荐的 agent 架构，其可追溯证据与人在回路模式可迁移到代码优化 agent 的验证环节。

TL;DR: 提出一种拓扑引导的GeoAI智能体框架，以确定性空间分析、语言模型受限决策和人工在环检查点实现透明、可审查的城市洪水初筛。


<details>
  <summary>Details</summary>
Motivation: 开放世界GeoAI智能体可用于将公共地理空间数据转化为现实决策支持，但需在自主推理、可靠空间分析与人工监督之间取得平衡，尤其在高后果的洪水筛查场景中保持建议可审查和用户可控。

Method: 构建拓扑引导的GeoAI智能体框架：确定性控制器检索高程、降雨、土壤、土地覆盖、暴露度和基础设施等公共图层，用离散莫尔斯理论提取地形洼地，并以相对洪水优先级评分排序候选盆地；语言模型仅在记录决策点执行阈值选择、证据驱动建议起草和基于同一证据的建议审查；设置三个人工在环检查点供用户修改阈值、因子权重或建议。

Result: 在College Park案例中，所选持续性阈值将278个原始地形极小值缩减为70个盆地，其中77%的盆地最低点与单独D8流向模型识别的汇点一致；在另外四个研究区，一致率为61%至83%。

Conclusion: 该框架结合开放数据、显式空间推理、可追溯证据和人工监督，可实现透明的首轮洪水筛查，并使重要建议保持可检查、可追溯和用户可控。

中文摘要：开放世界地理人工智能（GeoAI）智能体能够将公共地理空间数据转化为面向现实挑战的可及决策支持，但必须在自主推理与可靠空间分析及人工监督之间取得平衡。我们提出一种拓扑引导的GeoAI智能体框架，用于城市洪水筛查；该框架接受地名、绘制的区域或上传的边界作为输入，并返回带交互式地图和报告的排序候选盆地。确定性控制器检索公共高程、降雨、土壤、土地覆盖、暴露度和基础设施图层，利用离散莫尔斯理论提取地形洼地，并用相对洪水优先级评分对盆地进行排序。语言模型仅在记录下来的决策点采取行动：从预计算的候选表中选择持续性阈值、根据计算得到的证据起草建议，并对照同一证据审查每条建议。三个人工在环检查点允许用户修改阈值、因子权重或建议。在马里兰州College Park的案例研究中，所选阈值将278个原始地形极小值缩减为70个盆地，其中77%的盆地最低点也被单独计算的八方向（D8）流向模型识别为汇点。在另外四个研究区中，一致率为61%至83%。通过结合开放数据、显式空间推理、可追溯证据和人工监督，该框架实现了透明的首轮洪水筛查，同时使重要建议保持可审查且由用户控制。

Original abstract: Open-world geographic artificial intelligence (GeoAI) agents can transform public geospatial data into accessible decision support for real-world challenges, but must balance autonomous reasoning with reliable spatial analysis and human oversight. We present a topology-guided GeoAI agentic framework for urban flood screening that takes a place name, drawn region, or uploaded boundary and returns ranked candidate basins with an interactive map and report. A deterministic controller retrieves public elevation, rainfall, soil, land-cover, exposure, and infrastructure layers, extracts terrain depressions with discrete Morse theory, and ranks basins with a relative flood-priority score. The language model acts only at recorded decision points: selecting a persistence threshold from a precomputed candidate table, drafting recommendations from computed evidence, and reviewing each recommendation against the same evidence. Three human-in-the-loop checkpoints let users revise the threshold, factor weights, or recommendation. In a College Park, Maryland case study, the selected threshold reduced 278 raw terrain minima to 70 basins, with 77% of these basins' lowest points also identified as sinks by a separately computed eight-direction (D8) flow-routing model. Across four further study areas, agreement ranged from 61% to 83%. By combining open data, explicit spatial reasoning, traceable evidence, and human oversight, the framework enables transparent first-pass flood screening while keeping consequential recommendations inspectable and user-controlled.

### [2] [DConstrain: Compiling Context-Parameterized Transitions for Diffusion Language Model Constrained Decoding](https://arxiv.org/abs/2610.30920)
*Shidong Cao,Jing Ma,Wenhao Chai,Yuchen Tian,Lun Du,Da Zheng*

Main category: cs.AI

Comments: 39 pages, 6 figures, 12 tables

Selection reason: 把 schema 编译为上下文参数化转移程序以做精确约束解码，提升函数调用 schema 合法率与解码效率，对 agent 工具调用/结构化输出的可靠性有可迁移价值。

TL;DR: DConstrain 通过将 schema 编译为上下文参数化转移程序，结合冷/热编译、运行时字段历史跟踪和 token 效果分组，实现任意属性顺序下精确且高效的约束扩散解码。


<details>
  <summary>Details</summary>
Motivation: DLM 并行解码可能产生单独有效但联合不兼容的 token；精确语法图联合推理虽能保证兼容性，却依赖大量解析器配置上的带标签后继，且栈和字段历史进入编译状态会导致指数增长，使已有精确解码器固定属性顺序并排除有效输出。

Method: DConstrain 将 schema 编译为上下文参数化转移程序；冷编译把 token 消耗特化到局部语法状态，并以符号方式保留上下文相关栈操作、环境守卫和调用者相关延迟解析；字段历史作为运行时值跟踪以支持任意属性顺序；热编译在运行时绑定到达配置以构造精确后继，并与模型前向传播重叠；token 效果分组在绑定运行时上下文前合并相同编译效果的 token；目标特定分数聚合与 token 恢复保持 Viterbi 最优解和带 token 标签的路径分布。

Result: 在三个基准和两个 DLM 系列上，DConstrain 在任意属性顺序下编译 100% 的 BFCL schema，而优化的有限状态基线仅编译 71.30-85.81%；在任意属性顺序下，BFCL 端到端解码延迟降低 6.65-46.26 倍且 schema 有效性为 100%，并将 DiffusionGemma 的 BFCL 准确率从固定顺序下的 37.27% 提高到 81.56%。

Conclusion: DConstrain 为 DLM 提供了一种精确、高效且支持任意属性顺序的约束解码方案，在 schema 编译覆盖率、解码延迟和准确率上优于固定顺序或有限状态基线。

中文摘要：扩散语言模型（DLM）并行解码多个 token，因此在某个 schema 下，单独有效的 token 可能彼此不兼容。在语法图上的精确联合推理能够强制兼容性，但它需要在许多假想解析器配置上获得带 token 标签的后继。将栈和字段历史编码进编译状态可能导致指数级增长，这迫使此前的精确解码器固定属性顺序并排除有效输出。我们提出 DConstrain，它将 schema 编译为上下文参数化的转移程序。冷编译将 token 消耗特化到局部语法状态，同时以符号方式保留上下文相关栈操作、环境守卫和依赖调用者的延迟解析。将字段历史作为运行时值跟踪，可支持任意属性顺序，而无需离线枚举字段子集。运行时，热编译将到达的配置绑定到这些程序以构造精确后继，并与模型前向传播重叠，因为图构造不需要模型分数。此外，token 效果分组在绑定运行时上下文之前合并具有相同编译效果的 token，因此即使具体后继不同，分组也可跨栈和环境复用。目标特定的分数聚合和 token 恢复可证明地保持未分组推理的 Viterbi 最优解和带 token 标签的路径分布。在三个基准和两个 DLM 系列上，DConstrain 在任意属性顺序下编译 100% 的 BFCL schema，而优化的有限状态基线仅编译 71.30-85.81%。在任意属性顺序下，它将 BFCL 端到端解码延迟降低 6.65-46.26 倍，并具有 100% schema 有效性，同时将 DiffusionGemma 的 BFCL 准确率从固定顺序下的 37.27% 提高到 81.56%。

Original abstract: Diffusion language models (DLMs) decode multiple tokens in parallel, so individually valid tokens can be incompatible together under a schema. Exact joint inference over a grammar graph enforces compatibility, but it requires token-labeled successors across many hypothetical parser configurations. Encoding stacks and field histories in compiled states can cause exponential growth, which forces prior exact decoders to fix property orders and exclude valid outputs. We present DConstrain, which compiles schemas into context-parameterized transition programs. Cold compilation specializes token consumption to local grammar states while retaining context-dependent stack operations, environment guards, and caller-dependent deferred parsing symbolically. Tracking field histories as runtime values supports arbitrary property order without enumerating field subsets offline. At runtime, warm compilation binds reached configurations to these programs to construct exact successors, overlapping with the model forward pass because graph construction requires no model scores. Furthermore, token-effect grouping merges tokens with identical compiled effects before runtime contexts are bound, so groups are reused across stacks and environments even when concrete successors differ. Objective-specific score aggregation and token restoration provably preserve both the Viterbi optimum and the token-labeled path distribution of ungrouped inference. Across three benchmarks and two DLM families, DConstrain compiles 100% of BFCL schemas under arbitrary property orders, whereas an optimized finite-state baseline compiles only 71.30-85.81%. Under arbitrary property order, it reduces BFCL end-to-end decoding latency by 6.65-46.26 times with 100% schema validity and raises DiffusionGemma's BFCL accuracy from 37.27% under fixed order to 81.56%.

### [3] [Beyond Causal Masks: Auditing and Localizing Hidden Future-Token Leakage in Adaptive Sequence Models](https://arxiv.org/abs/2610.31522)
*Huiting Liu,Jinsong Wu*

Main category: cs.AI



Selection reason: 揭示隐藏未来信息泄漏会造成虚假性能增益，并给出前缀不变性审计与泄漏度量方法，这种“表面指标提升需配合整体行为校验”的思路可迁移到自动代码优化中的 speedup 可信性验证。

TL;DR: 隐藏未来 token 泄漏会让模型在教师强制评估下虚低损失，但自由生成变差；本文定位自适应残差路由解码器中的泄漏路径，并用因果修复消除虚假优势。


<details>
  <summary>Details</summary>
Motivation: 研究自回归模型在教师强制评估中因隐藏未来 token 泄漏而获得虚假架构收益的问题，尤其是正确因果掩码下仍存在的未来信息暴露。

Method: 针对自适应残差路由解码器，使用前缀不变性审计、最大前缀输出差异（LeakScore）、互补行为指标和逐层诊断，并结合实现检查、合成实现对、预训练对照、故障注入和缓存一致性实验定位泄漏。

Result: 异常 24 层检查点将验证损失从 3.5958 降至 1.4259，但未通过前缀不变性审计且生成时参考模型困惑度显著更高；泄漏源于经动态路由查询路径广播的全序列摘要。两个独立训练的 12 层因果修复消除可检测泄漏，使验证损失和参考困惑度回到对照水平，表观优势消失。

Conclusion: 隐藏未来 token 访问可导致误导性的架构进展结论；更低的教师强制损失必须与全模型因果检查和自由运行生成评估结合解读。

中文摘要：隐藏的未来 token 泄漏可能制造虚假的架构收益：自回归模型在教师强制评估下可能看起来显著更好，而其自由运行生成却会退化。我们研究了一种自适应残差路由解码器中的这一失效，该解码器的序列级路由摘要会尽管因果注意力掩码正确，仍将前缀位置暴露给未来 token。一个异常的 24 层检查点将验证损失从基线的 3.5958 降至 1.4259，但它未通过前缀不变性审计，并且在生成期间具有显著更高的参考模型困惑度。逐层诊断与实现检查将违规追溯到通过动态路由查询路径广播的全序列摘要。两个独立训练的 12 层因果修复消除了可检测泄漏，并将验证损失和参考困惑度恢复到对照水平，从而移除了巨大的表观优势。作为诊断工具，我们使用既有的前缀不变性契约、最大前缀输出差异（LeakScore）、互补行为指标以及逐层剖面。支持实验涵盖六个合成实现对，跨越五个模块族、干净预训练对照、受控故障注入，以及跨数值精度的缓存一致性。这些结果说明了隐藏的未来 token 访问如何能够产生误导性的架构进展声明，以及为什么更低的教师强制损失应与全模型因果检查和自由运行评估结合解读。

Original abstract: Hidden future-token leakage can create false architectural gains: an autoregressive model may appear substantially better under teacher-forced evaluation while its free-running generation deteriorates. We investigate this failure in an adaptive residual-routing decoder whose sequence-level routing summary exposes prefix positions to future tokens despite a correct causal attention mask. An anomalous 24-layer checkpoint reduces validation loss from the baseline's 3.5958 to 1.4259, yet it fails a prefix-invariance audit and has substantially higher reference-model perplexity during generation. Layer-wise diagnostics and implementation inspection trace the violation to a full-sequence summary broadcast through the dynamic routing-query path. Two independently trained 12-layer causal repairs eliminate detectable leakage and return validation loss and reference perplexity to the control scale, removing the large apparent advantage. As diagnostic tools, we use the established prefix-invariance contract, maximum prefix-output discrepancy (LeakScore), complementary behavioral metrics, and layer-wise profiles. Supporting experiments cover six synthetic implementation pairs spanning five module families, clean pretrained controls, controlled fault injection, and cache consistency across numerical precisions. These results illustrate how hidden future-token access can produce misleading claims of architectural progress and why lower teacher-forced loss should be interpreted together with whole-model causal checks and free-running evaluation.
