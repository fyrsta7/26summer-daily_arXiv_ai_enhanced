Selection reason: 研究多智能体审阅者何时被授权覆盖上游决策的证据门控机制，对 coding agent 的验证/审阅与自我修正接口设计有直接启发。

Motivation: 评审者可能修复上游错误，也可能覆盖正确决策，因此需要明确其在何种条件下有权使建议具有约束力。

Method: 比较宽泛覆盖权限与证据门控；使用两个本地开源权重模型、96个空间策略任务和96任务组合迁移基准，并进行保留/替换/上报的前瞻性验证。

中文摘要：多智能体语言模型系统常常加入一个评审者，以改进上游智能体的决策。然而，评审者既能修复错误，也能替换本来已经正确的决策。我们将此作为一个制度性管辖权问题来研究：在给定相同提案、任务信息、模型和评审输出的条件下，评审者何时有权使其建议具有约束力？我们比较宽泛的覆盖权限与一种证据门控：只有当评审者产出一个机械上有效的记录，证明存在绑定约束违反并给出合规修复后，才允许替换。在两个本地运行的开源权重模型、96个空间策略任务以及一个96任务组合迁移基准上，该门控大幅减少了正确提案被破坏的情况，同时保留了大多数对违规的修复。这种权衡的方向部分由规则本身蕴含；其幅度取决于评审者状态转移和上游提案状态。一项前瞻性验证随后赋予评审者显式选择：保留、替换或上报。这消除了Qwen对正确提案的破坏，但Mistral仍替换全部48个正确提案；Qwen还拒绝了Mistral频繁尝试的每一个仅福利修复。因此，界面设计会改变评审者行为，但并非独立于模型的安全保障。结果并不是受限评审普遍更好。而是：评审者能力、动作界面和具有约束力的管辖权共同决定纠正域和破坏面。

Original abstract: Multi-agent language-model systems often add a reviewer to improve an upstream agent's decision. Yet a reviewer can both repair errors and replace decisions that were already correct. We study this as a problem of institutional jurisdiction: conditional on the same proposal, task information, model, and review output, when is the reviewer authorized to make its recommendation binding? We compare broad override authority with an evidence gate that permits replacement only after the reviewer produces a mechanically valid record of a binding-constraint violation and a compliant repair. Across two locally run open-weight models, 96 spatial-policy tasks, and a 96-task portfolio-transfer benchmark, the gate sharply reduces corruption of correct proposals while retaining most repairs of violations. The directions of this tradeoff are partly implied by the rule; its magnitude depends on reviewer transitions and upstream proposal states. A prospective validation then gives the reviewer an explicit choice to retain, replace, or escalate. This eliminates correct-proposal corruption for Qwen, but Mistral still replaces all 48 correct proposals; Qwen also declines every welfare-only repair that Mistral frequently attempts. Thus interface design changes reviewer behavior but is not a model-independent safeguard. The result is not that restricted review is universally better. It is that reviewer competence, action interface, and binding jurisdiction jointly determine both the correction domain and the corruption surface.

Main category: cs.AI

Comments: 9 pages, 3 figures

Selection reason: 提出 harness 感知架构，在关键动作前向模型注入经过验证的运行时/工具健康状态，属于工具使用 agent 的 harness 与反馈机制创新。

We introduce Agent Harness Awareness, a trust-separated design in which the host supplies a small, fresh, verified state snapshot before a consequential action while retaining measurement, enforcement, evaluation, and final dispatch authority. We test its tools-and-network instance with ToolRoute, a controlled isolation benchmark that holds the task and candidate semantics constant and varies the operational information available to the model. These studies establish the tools-and-network instance of Agent Harness Awareness: selected host telemetry materially improves pre-dispatch operational choice. Runtime state, hardware pressure, economics, retry-aware recovery, and heterogeneous selection remain open empirical extensions of the same architecture.
