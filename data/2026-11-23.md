### [1] [Training LLMs to Follow Reasoning Instructions with Minimal Edits](https://arxiv.org/abs/2611.26342)
*Alexandra Yakovleva,Luat Gia Khoi Nguyen,Juho Kannala,Harri Valpola,Alexander Ilin*

Main category: cs.AI

Comments: Accepted at the NeurIPS 2026 Workshop on Transitioning from Pre-training to Post-training

Selection reason: 提出基于编辑的轨迹训练方法，通过定位推理失败点并进行局部修正来学习，可迁移至coding agent从执行轨迹中迭代改进的训练范式

TL;DR: 本文提出基于编辑的训练框架，通过在模型推理轨迹的局部失败点进行最小文本修正来进行监督，解决了全轨迹微调和轨迹级强化学习中训练信号粗糙的问题，显著提升了大模型的推理指令遵循能力。


<details>
  <summary>Details</summary>
Motivation: 现有的全轨迹监督微调会过度约束模型输出分布，而轨迹级强化学习缺乏细粒度的信用分配，无法精确定位推理过程中的失败点，导致训练信号过于粗糙。

Method: 提出基于编辑的训练框架。在模型采样的推理轨迹中，利用编辑器识别首个失败点并生成最小替换文本跨度，仅对这些局部编辑区域进行监督训练。该方法支持离线和在线模式，将监督信号精准集中在推理崩溃的局部位置，同时保留模型原有的正确推理模式。

Result: 在ReasonIF基准上使用Qwen3-32B的实验表明，与全轨迹模仿和轨迹级强化学习基线相比，该方法显著提高了模型对推理指令的遵循度，并有效保留了模型在未目标任务上的原有技能。

Conclusion: 局部文本修正是塑造大语言模型推理方式的有效补充方法，能够精准提供训练信号并避免破坏模型已有的推理能力。

中文摘要：大型语言模型越来越依赖扩展的推理轨迹，但用于塑造这种行为的训练信号仍然很粗糙。在完整轨迹上进行监督微调迫使模型模仿整个演示，过度约束了其输出分布，而轨迹级强化学习仅提供微弱的信用分配，对整个完成进行奖励或惩罚，而无法识别其成功或失败的具体位置。我们提出了基于编辑的训练，这是一个通过局部文本修正从模型自身轨迹中学习的通用框架。给定一个采样的完成结果，编辑器在指定标准下识别出第一个失败点，并提出一个最小的替换跨度。然后仅对这些编辑后的跨度对模型进行监督。通过设计，这种方法将监督集中在模型推理首次崩溃的地方，并旨在保留其在其他地方的现有推理模式。该方法同时适用于离线和在线场景，后者不断调整监督以适应模型不断变化的失败模式。我们在ReasonIF基准上使用Qwen3-32B对推理指令遵循实例化了这种方法。与完整轨迹模仿和轨迹级强化学习基线相比，基于编辑的训练大幅提高了对推理指令的遵循度，同时很大程度上保留了模型在未目标任务上的技能。这些结果表明，局部修正是塑造大型语言模型推理方式的有效补充。

Original abstract: Large language models increasingly rely on extended reasoning traces, yet the training signals used to shape this behavior remain coarse. Supervised fine-tuning on full trajectories forces the model to imitate an entire demonstration, overconstraining its output distribution, while trajectory-level reinforcement learning provides only weak credit assignment, rewarding or penalizing whole completions without identifying where they succeed or fail. We propose edit-based training, a general framework for learning from a model's own trajectories via localized textual corrections. Given a sampled completion, an editor identifies the first point of failure under a specified criterion and proposes a minimal replacement span. The model is then supervised only on these edited spans. By design, this concentrates supervision where the model's reasoning first breaks down and aims to preserve its existing reasoning patterns elsewhere. The method applies both offline and online, with the latter continually adapting supervision to the model's evolving failure modes. We instantiate this approach on reasoning instruction following with Qwen3-32B on the ReasonIF benchmark. Compared to full-trajectory imitation and trajectory-level reinforcement learning baselines, edit-based training substantially improves compliance with the reasoning instruction while largely preserving the model's skills on untargeted tasks. These results suggest that localized correction is an effective complement to these approaches for shaping how LLMs reason.

### [2] [FLUID: Flexible, Evidence-Grounded Situated Task Guidance](https://arxiv.org/abs/2611.26491)
*Yunqi Zhao,Run Peng,Ze Dong,Ryan Lu,Yinpei Dai,Joyce Chai*

Main category: cs.AI



Selection reason: 提出灵活任务引导agent框架，涉及基于证据的干预时机决策和实时交互，对agent的自适应行为设计有参考价值

TL;DR: 提出FLUID框架，通过引入基于证据和时机灵活性的评估与建模方法，解决多模态任务指导中现有基准缺乏灵活性的问题，并构建了一个在响应正确性、精确性和及时性上表现优异的实时指导智能体。


<details>
  <summary>Details</summary>
Motivation: 现有的任务指导基准测试通常将合成对话视为固定的内容和时机目标，忽略了实时任务指导中固有的灵活性（如多种合适的响应、时机选择甚至保持沉默），导致无法有效评估和实现自然、自适应的人机交互。

Method: 提出FLUID（灵活的、基于证据的情境任务指导）统一框架。利用WTaG和HoloAssist数据集中自然发生的人对人指导数据，将干预措施锚定在其支持证据、必要性和时机灵活性上。利用该表示方法评估灵活指导，并构建实时任务指导智能体。

Result: 所构建的智能体在评估系统中实现了响应正确性、干预精确性、及时指导和响应延迟的最佳整体平衡，但在避免语音重叠方面仍有改进空间。

Conclusion: FLUID框架成功将情境任务指导从僵化的参考匹配转变为更自然、自适应的人机交互，为多模态任务指导中的灵活交互提供了有效的建模、评估和实现方案。

中文摘要：实时任务指导本质上具有灵活性：当智能体引导用户完成任务时，多种响应和时机都是合适的，有时最好的行动是保持沉默。现有的基准测试通常通过将合成的对话视为说什么和何时说的固定目标而忽略了这种灵活性。我们引入了FLUID（灵活的、基于证据的情境任务指导），这是一个用于多模态任务指导中建模、评估和实现灵活交互的统一框架。利用来自WTaG和HoloAssist的自然发生的人对人指导，FLUID将干预措施建立在其支持证据、必要性和时机灵活性的基础上，并使用这种表示来评估灵活指导并构建用于任务指导的实时智能体。我们的智能体在评估系统中实现了响应正确性、干预精确性、及时指导和响应延迟的最强整体平衡，同时在避免语音重叠方面仍有改进的空间。总而言之，FLUID将情境任务指导从僵化的参考匹配推向更自然、自适应的人机交互。项目主页：https://fluid-guidance.github.io。

Original abstract: Real-time task guidance is inherently flexible: when an agent guides a user through a task, multiple responses and timings can be appropriate, and sometimes the best action is to remain silent. Existing benchmarks often miss this flexibility by treating synthesized dialogues as fixed targets for what to say and when to say it. We introduce FLUID (Flexible, Evidence-Grounded Situated Task Guidance), a unified framework for modeling, evaluating, and enabling flexible interaction in multimodal task guidance. Using naturally occurring human-human guidance from WTaG and HoloAssist, FLUID grounds interventions in their supporting evidence, necessity, and timing flexibility, and uses this representation both to evaluate flexible guidance and to build a real-time agent for task guidance. Our agent achieves the strongest overall balance of response correctness, intervention precision, timely guidance, and response latency among evaluated systems, while still leaving room for improvement in avoiding speech overlap. Together, FLUID moves situated task guidance beyond rigid reference matching toward more natural and adaptive human-AI interaction. Project page: https://fluid-guidance.github.io.
